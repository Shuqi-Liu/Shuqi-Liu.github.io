# shuqi-liu.github.io

Personal site for Shuqi Liu with access to papers and poster pdfs. 

## Files
- `index.html`: the whole site (HTML + CSS in one file). Edit text directly here.
- `assets/Liu-SfN2026-poster.pdf`: full-resolution poster
- `assets/poster-1200.jpg`, `assets/poster-2400.jpg`: poster images shown on the page
- `assets/og-image.jpg`: preview image when the link is shared (Slack, LinkedIn, iMessage)
- `assets/Shuqi-Liu-CV.pdf`: downloadable CV
- `.nojekyll`: tells GitHub Pages to serve files as-is

## Updating
- New CV: replace `assets/Shuqi-Liu-CV.pdf` (same filename) and edit the CV section in `index.html`.
- New poster: replace the PDF and regenerate the two JPGs at the same filenames.
